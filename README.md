# Weather practice

Небольшая консольная утилита для получения погоды по городам и определенному количетсву днея (от 1 до 7) с использованием стороннего API, в частности **Open-Meteo API**. Программа получает координаты по введенному пользователем списком городов, отправляет запрос

## Установка

Клонировать репозиторий и установить зависимости:

```bash
yarn install
```

## Настройка

```env
GEOCODING_URL=https://geocoding-api.open-meteo.com/v1/search
FORECAST_URL=https://api.open-meteo.com/v1/forecast
REQUEST_TIMEOUT=5000
REPORTS_DIR=./reports
```

Файл `.env` не добавляется в Git.

## Запуск

### Один город

```bash
yarn tsx src/index.ts --city "Нижний Новгород"
```

По умолчанию запрашивается прогноз на 3 дня.

### Указать количество дней

```bash
yarn tsx src/index.ts --city "Нижний Новгород" --days 5
```

Допустимый диапазон: от 1 до 7 дней.

### Несколько городов

```bash
yarn tsx src/index.ts --city "Москва,Казань,Нижний Новгород" --days 3
```

Города обрабатываются параллельно. Ошибка при обработке одного города не останавливает обработку остальных.

### Игнорировать кэш

Для принудительного получения свежих данных используется:

```bash
yarn tsx src/index.ts --city "Нижний Новгород" --days 3 --no-cache
```

## Кэширование

После успешного получения прогноза результат сохраняется в директории `reports`.

Имя файла формируется по городу и текущей дате:

```text
reports/Нижний Новгород-2026-09-13.json
```

Если отчёт за текущую дату уже существует, программа использует данные из файла и не выполняет повторный запрос к API.

Флаг `--no-cache` отключает использование кэша и заставляет программу выполнить запрос заново.

Директория `reports` не добавляется в Git.

## Формат вывода

Для каждого города выводятся:

- название города;
- страна;
- координаты;
- прогноз по дням;
- минимальная температура;
- максимальная температура;
- суммарные осадки.

Пример:

```text
Нижний Новгород

Россия
Координаты: 56.3269, 44.0059

┌─────────┬──────────────┬─────────┬─────────┬──────────────┐
│ (index) │ Дата         │ Мин. °C │ Макс. °C │ Осадки, мм │
├─────────┼──────────────┼─────────┼─────────┼──────────────┤
│ 0       │ 2026-09-13   │ 8       │ 15      │ 0.2          │
└─────────┴──────────────┴─────────┴─────────┴──────────────┘
```

## Код завершения

Программа использует следующие коды завершения:

- `0` — успешное выполнение;
- `1` — ошибка.
